# Publication and frozen hashes

This is the completed correct HY104-EMA22/SI comparison:14 local arms and4 real
DeepInfra arms,159 actual native setups,110 identical later test cases.

Private inputs,raw market quotes,individual SI/message IDs,case rows,prediction
rows,keys,authorization,controller/key-form code and private Claude URLs are NOT
published. MLflow run IDs are included at the user's explicit request;the server
links point to the user's local MLflow,not a public hosted tracker.

Executed Source files are copied byte-for-byte. Public dataset-manifest paths
are relative Private placeholders;the files they name remain local. Other JSON
values are sanitized/normalized for publication. Existing freeze and binding
digests refer to ORIGINAL LOCAL FILES. They must not be claimed as hashes of the
modified public rendering. export-manifest.json lists ORIGINAL and PUBLISHED
SHA256 separately for every staged file. Restore the original workspace layout
and privately held licensed inputs to rerun;the public tree alone is not a full
market-data package.

The uncalibrated-margin classifiers have no invented probability metrics.
Probabilities from other models were not treated as proven trading calibration.
This is selected development data with only8 recent15m/26 recent60m SI test
matches,not fresh OOS,a live trading change,a provider payout backtest or a
universal claim that SI has no information.

Built with PriorLabs-TabPFN. The pinned local v2 checkpoint and version-specific
license evidence remain in the original research installation;weights are not
included here.

comparison.png is an optional separately uploaded aggregate scientific plot.
It has no raw cases,market quotes or credential values.
